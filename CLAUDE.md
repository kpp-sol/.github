# Инструкции для ИИ-агентов — репозиторий .github

> Две одинаковые копии: `AGENTS.md` (Codex) и `CLAUDE.md` (Claude Code). Меняешь один — `cp AGENTS.md CLAUDE.md`.

Общие правила студии — в `knowledge/AGENTS.md`.

Репозиторий **публичный**: всё, что здесь лежит, видно всем. Ничего внутреннего сюда не пишем.

- `profile/README.md` — публичная страница организации на GitHub.
- `ISSUE_TEMPLATE/` и `pull_request_template.md` — формы задач и шаблон PR по умолчанию для всех репозиториев организации, у которых нет своих. Формы сами добавляют задачу на доску `kpp-sol/2`.
